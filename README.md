# Power BI Sales Performance Dashboard

## Project Overview
This is my beginner-level Power BI project created as part of my Data Analytics learning journey.

## Tools Used
- Microsoft Power BI Desktop
- Microsoft Excel
- DAX

## Features
- Total Sales KPI Card
- Sales by Product Category
- City-based interactive slicer
- City-wise sales analysis

## Skills Practiced
- Importing Excel data
- Creating calculated columns using DAX
- Building charts and interactive dashboards

## Learning Outcome
This project helped me practice data visualization and interactive dashboard creation using Power BI.

- Power BI dashboard (.pbix)
- Practice sales dataset (.xlsx)
